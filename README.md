# NumPy Fundamentals Practice

A collection of exercises covering core NumPy operations — array creation, indexing, 
memory, linear algebra, and vectorized performance.

## What this covers

**Array creation & basics**
- Converting a list of numeric values into a 1D NumPy array
- Creating arrays of zeros with specific shapes (e.g. a 9-element array, a 12-dimensional 
  vector with one non-zero value at a set position)
- Creating a vector with a defined value range (20–59)
- Creating a 3×3 matrix with a defined value range (12–20)

**Array inspection & memory**
- Finding the memory size (in bytes) of an array
- Accessing NumPy's built-in documentation for functions (e.g. `np.add`) from the command line

**Indexing & transformation**
- Reversing a vector (first element becomes last)
- Finding indices of non-zero elements in a matrix

**Random arrays & statistics**
- Generating a 9×9 array of random numbers and finding its min/max values
- Generating a random vector and sorting it in ascending order
- Comparing two random arrays for equality

**Linear algebra**
- Creating a 6×3 and a 3×4 matrix and computing their matrix product

**Set operations**
- Finding common values between two arrays

**Dates**
- Generating all dates in January 2016 using NumPy's datetime functionality

**Performance**
- Extracting the integer part of positive random numbers using 4 different methods
- Comparing a custom summation approach against `np.sum` for speed

## Tools

Python, NumPy

## Note

This is a practice/fundamentals repo intended to demonstrate NumPy proficiency, not a 
data analysis project with a dataset or findings.
